A simple announcement UI for FiveM servers with sound notification and customizable design.

Script miễn phí dành cho cộng đồng FiveM Việt Nam.

---

## 📸 Preview

Video demo:  
https://youtu.be/r0sAVN4gn4M

---

## ✨ Features

- UI thông báo đẹp cho server
- Có âm thanh thông báo
- Có thể chỉnh trong `config.lua`
- Nhẹ và dễ sử dụng
- Phù hợp với mọi server FiveM

---

## 📦 Installation

1. Download script
2. Đặt thư mục `tx-announce-ui`
3. Thêm vào `server.cfg`

## ⚙️ Configuration

Bạn có thể chỉnh sửa trong file: để thay đổi nội dung thông báo, âm thanh hoặc giao diện.
