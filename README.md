# tx-announce-ui

![FiveM](https://img.shields.io/badge/FiveM-Script-orange)
![Free](https://img.shields.io/badge/Price-Free-green)

A simple announcement UI for FiveM servers with sound notification and customizable design.

Script miễn phí dành cho cộng đồng FiveM Việt Nam.

## ✨ Features

* UI thông báo đẹp cho server
* Có âm thanh thông báo
* Có thể chỉnh trong `config.lua`
* Nhẹ và dễ sử dụng
* Phù hợp với mọi server FiveM

---

## 📦 Installation

1. Download script
2. Đặt thư mục `tx-announce-ui` vào thư mục `resources` của server
3. Thêm vào file `server.cfg`

```
ensure tx-announce-ui
```

---

## ⚙️ Configuration

Bạn có thể chỉnh sửa trong file:

```
config.lua
```

để thay đổi nội dung thông báo, âm thanh hoặc giao diện.
